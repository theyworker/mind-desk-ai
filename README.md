# Mind Desk AI

A smart, voice-friendly reminders app built for CXOs and busy individuals. Just say what's on your mind for tomorrow, the app breaks it down into actionable tasks you can check off throughout the day.

## Features

- 🎤 Voice input for natural task creation
- 🧠 AI-powered task breakdown and organization
- ✅ Simple checkbox interface for task completion
- 📱 Mobile-first design for busy professionals
- 🚀 Built with Next.js, TypeScript, and Tailwind CSS

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Technology Stack

- **Framework**: Next.js 15 with App Router
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **AI Integration**: Ready for voice recognition and AI task processing
- **Deployment**: Optimized for Vercel deployment

## Development

You can start editing the page by modifying `src/app/page.tsx`. The page auto-updates as you edit the file.
